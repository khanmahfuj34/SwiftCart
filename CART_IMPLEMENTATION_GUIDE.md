## Data Attributes Reference

All buttons use data attributes for event delegation (no inline onclick):

| Attribute | Used For | Example |
|-----------|----------|---------|
| `data-inc-id="${item.id}"` | Increment quantity button | `<button data-inc-id="5">+</button>` |
| `data-dec-id="${item.id}"` | Decrement quantity button | `<button data-dec-id="5">-</button>` |
| `data-remove-id="${item.id}"` | Remove item button | `<button data-remove-id="5">Remove</button>` |

## JavaScript API

### Core Functions

#### Storage
```javascript
loadCartFromStorage()        // Load cart from localStorage on page load
saveCartToStorage()          // Save cart to localStorage (auto-called)
```

#### Adding/Removing
```javascript
addToCart(productId)         // Add product or increase qty if already in cart
removeFromCart(productId)    // Remove product completely from cart
changeQty(productId, delta)  // Change qty by delta (+1 or -1, min qty=1)
```

#### Calculations
```javascript
calculateSubtotal(cart)      // Returns numeric subtotal (price × qty sum)
```

#### Rendering
```javascript
renderCartDropdown()         // Re-render dropdown mini cart
renderCartPage()            // Re-render full view cart page
updateCartUI()              // Update badge & dropdown display
```

#### UI Control
```javascript
toggleCartPage(show)        // Show/hide cart page vs main sections
proceedToCheckout()         // Handle checkout button
```

## Data Model

Each cart item has this structure:
```javascript
{
  id: 1,                    // Product ID (number)
  title: "Item Name",       // Product title (string)
  price: 19.99,             // Unit price (number)
  image: "url...",          // Product image URL (string)
  quantity: 2               // Quantity in cart (number, min 1)
}
```

The cart is stored in localStorage under key: `swiftcart_cart`

## Event Flow

### Adding Product to Cart
1. User clicks "Add to Cart" on product card → `addToCart(id)`
2. Checks if product already in cart
3. If yes: increment `quantity`
4. If no: add new item with `quantity: 1`
5. `saveCartToStorage()` persists to localStorage
6. `updateCartUI()` refreshes badge & dropdown

### Quantity Changed (±)
1. User clicks +/- button with `data-inc-id` or `data-dec-id`
2. Event delegation handler calls `changeQty(id, delta)`
3. Updates `item.quantity` (min 1)
4. `saveCartToStorage()` + re-render both dropdown & page

### Remove Item
1. User clicks remove button with `data-remove-id`
2. Event delegation handler calls `removeFromCart(id)`
3. Removes from cart array
4. `saveCartToStorage()` + re-render both dropdown & page

### View Cart Button
1. User clicks "View Cart" button (id=`viewCartBtn`)
2. Event listener calls `toggleCartPage(true)`
3. Hides main sections, shows cart page
4. Renders full cart items with quantity controls
5. Closes dropdown by calling `closeDropdown()`

## Browser Compatibility

- Modern browsers (Chrome, Firefox, Safari, Edge)
- Uses `localStorage` API
- Using `closest()` for event delegation (IE not supported)
- Requires Tailwind CSS + DaisyUI CDN

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Cart empty after refresh | Check localStorage in DevTools (key: `swiftcart_cart`) |
| Qty buttons not working | Ensure `data-inc-id` / `data-dec-id` attributes are present |
| Remove buttons not responding | Check that `data-remove-id` is set correctly |
| Subtotal shows NaN | Ensure `item.price` is a number, not a string |
| Dropdown won't close | Make sure `viewCartBtn` ID is present in HTML |
